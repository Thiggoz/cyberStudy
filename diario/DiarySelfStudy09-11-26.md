## 🖥️ Introduction to tcpdump

I won't lie, this room was pretty different from the others and I ran into several problems with it, actually the first time I had this kind of trouble.

In short, the room introduces a tool that comes built into most operating systems called **tcpdump**. It captures packets much like **Wireshark**, but it's entirely command line based, so it works in a different way since everything is done through commands. I managed to understand its purpose well enough: it examines packets, doing basically the same job as Wireshark, just in a much more limited way.

I had some trouble with the filtering part because, inside my virtual machine for the project, I couldn't find the files I needed. I even tried using the room's AI assistant for help, but that didn't work either. There were a few exercises I wasn't able to solve the way I wanted, and getting help wasn't easy either, so overall there were quite a few points where I struggled with TryHackMe today. Aside from that, everything else went fine.

This room is really just an introduction to the tool, so there isn't much more to say about it. I found tcpdump a bit odd, since it does the same job as Wireshark but in a much rougher way. It could really use more of a visual interface to help the user, but it still gets the job done for capturing packets.
